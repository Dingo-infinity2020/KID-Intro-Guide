# References / Evidence Plan

v0.1 先搭结构，不在没有证据的情况下提前写死具体 recipe。后续资料按以下优先级进入正文。

## A. 本地加工平台一手资料

1. 实验室正式 SOP / training slides
2. 设备管理员给出的 material policy、recipe policy、calibration/maintenance 说明
3. 实际 run log、witness sample、metrology 数据

这些资料决定“我们实际上能怎么做”，优先级高于网上通用 recipe。

## B. 器件与材料论文

优先收集：

- KID / MKID fabrication process papers
- Al / TiN / Nb 等薄膜材料性质与 KID performance 的关联
- surface/interface loss、TLS、etch/lithography damage
- array frequency scatter / fabrication tolerance / yield
- packaging / grounding / parasitic modes

## C. 设备厂商手册

用于理解设备参数定义和能力边界，不把 vendor nominal spec 直接当成我们平台的 process capability。

## D. 教材与 review

用于补 cleanroom、lithography、PVD、etch、metrology 的基础概念。

## 引用规则

正文中出现具体数值范围、材料结论、工艺窗口或性能因果时，必须能指向 A/B/C/D 中的明确证据；经验性判断要标明是“工程经验/待验证假设”，不要写成普适定律。
