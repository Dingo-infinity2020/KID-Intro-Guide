# KID 入门讲义 v0.5

主题：**微波谐振器与 IQ 读出：从 Q 到可拟合的 S21**。

本版本完整继承 v0.4，并新增：

- `Qi/Qc/Qr` 的能量与损耗率定义；
- linewidth 与 ring-down 的统一推导；
- ideal hanger/notch `S21`；
- IQ circle 的解析圆方程；
- fixed-tone readout 与 frequency/dissipation quadrature；
- cable delay、complex gain、asymmetry 与实际 resonance fitting；
- 两个可运行 Python 示例。
