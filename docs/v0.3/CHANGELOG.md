# v0.3 Changelog — 2026-09-04

## 新增

- 新增第 4 章“超导基础最小知识集：Cooper pair、能隙与准粒子”；
- 建立 normal state 与 superconducting state 的低能激发谱对比；
- 引入 BCS quasiparticle dispersion `E = sqrt(xi^2 + Delta^2)`；
- 系统解释 Cooper pair 与 quasiparticle 的物理含义；
- 引入弱耦合关系 `Delta0 ≈ 1.764 kB Tc`；
- 推出低温 pair-breaking cutoff `nu_pb ≈ 73.5 GHz/K × Tc`；
- 增加 Ti / Al / Nb / NbTiN 的代表性 pair-breaking 频率表；
- 引入 BCS density of states；
- 引入热准粒子低温近似 `nqp ∝ exp(-Delta/kBT)`；
- 增加 `T/Tc` 的数量级比较；
- 新增光生准粒子的能量级联流程图；
- 新增 generation–recombination 最小速率方程；
- 新增 quasiparticle lifetime 与 resonator ring-down time 的比较；
- 建立 `T/Tc` 与 `hν/2Delta` 两条材料选择主轴；
- 将上述内容映射到当前 150 GHz 双偏振 LEKID。
