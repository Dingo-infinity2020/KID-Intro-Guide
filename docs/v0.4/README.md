## 本版本的核心结果

薄膜、`σ2 >> σ1` 的直观近似下：

- `Z□ ≈ 1/(tσ)`；
- `Lk,□ ≈ 1/(ω t σ2)`；
- `δf0/f0 ≈ (α/2) δσ2/σ2`；
- `1/Qi,qp ≈ α σ1/σ2`。

同时新增了一个与当前 150 GHz LEKID 项目直接相关的建模约束：**GHz 读出端拟合出的单频 sheet impedance 不能无条件直接用于 150 GHz absorber。**
