# Pre-fabrication release checklist

- [ ] Nominal geometry has a unique commit/tag and parameter ledger.
- [ ] Conductor continuity and DRC pass.
- [ ] GHz Sonnet target mode, f0, Qc and current map pass.
- [ ] TE11-X / TE11-Y modal power closure passes.
- [ ] TM01 is included in the 149–151 GHz propagating-mode accounting.
- [ ] B0/B1 primary FOMs and PASS rules were defined before the final sweep.
- [ ] Mesh, frequency sampling and adaptive reproducibility are below the claim margin.
- [ ] Superconducting-material sensitivity has been checked.
- [ ] Manufacturing tolerances and alignment errors have been checked.
- [ ] GDS/CAD and simulation geometry have a traceable common source.
- [ ] Cryogenic VNA plan is frozen.
- [ ] Optical/polarization fixture can test the intended paper claim.
