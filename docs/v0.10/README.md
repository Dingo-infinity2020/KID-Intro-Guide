# KID 入门讲义 v0.10

这是 v0.10 的冻结发布目录。

- `KID入门讲义_v0.10.pdf`：正式阅读版
- `KID入门讲义_v0.10.tex`：权威排版源文件
- `KID入门讲义_v0.10.md`：便于检索、审阅和二次编辑的内容源文件
- `examples/`：与正文配套的可执行 Python 示例
- `templates/`：项目验证、仿真记录与加工前检查模板
- `CHANGELOG.md`：本版本主要修改
- `RELEASE_AUDIT.md`：发布门禁与可复现性记录

本版本的核心目标是让完全新手也能沿“光 → 超导状态 → 谐振器 → 微波读出 → 灵敏度 → LEKID 工程设计”逐步进入 KID，同时保留足够严格的公式条件、仿真边界与验证方法。
