# KID 入门讲义 v0.6

主题：**光学响应、噪声与 NEP：把“看到光”变成可比较的灵敏度指标**。

本版本完整继承 v0.5，并新增：
- `P_abs -> Gamma_qp -> N_qp` 的光学响应链；
- pair-breaking efficiency 与 quasiparticle lifetime；
- frequency / dissipation / I-Q responsivity；
- quasiparticle 与 resonator 两个动态时间尺度；
- PSD / ASD / NEP 的单位与 input-referred noise；
- photon、GR、TLS、amplifier/readout noise；
- 150 GHz Al LEKID 数值例子；
- 两个新的 Python 示例，并继承 v0.5 的两个 resonator 示例。

正式文件包括 PDF、LaTeX、Markdown、CHANGELOG 和 `examples/`。
