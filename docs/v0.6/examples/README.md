# v0.6 Python examples

本目录对应 v0.5-v0.6 的可运行数值练习：

- `resonator_basics.py`：ideal notch、IQ circle、frequency shift 与 fixed-tone response；
- `resonator_fit_demo.py`：包含 complex gain、cable delay、asymmetry 与噪声的拟合示例；
- `optical_responsivity_demo.py`：`P_abs -> Nqp -> δf0/f0`，以及 quasiparticle lifetime 对响应带宽的限制；
- `noise_budget_demo.py`：photon / GR NEP，以及 measured fractional-frequency noise 的 input-referred NEP。

这些脚本是教学用最小模型。真实器件分析时，应替换为实际材料、光学效率、带宽、MB 模型与 PSD convention。
